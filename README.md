# Stock Management System

## Overview

A university group project developed using Java and JavaFX to manage product inventory.

## Technologies

* Java
* JavaFX
* Object-Oriented Programming

## My Contribution

I was responsible for implementing the **Television** and **Refrigerator** product modules.

My work included:

* Designing the Television and Refrigerator classes
* Implementing inheritance from the base `Product` class
* Overriding methods for product-specific behaviour
* Working with stock information and product attributes within the assigned modules
* Testing the functionality of both product types

## Key Features

* Manage different product types
* Store product information and stock details
* Support Television and Refrigerator product modules
* Apply object-oriented programming principles

## OOP Concepts

* **Encapsulation**
* **Inheritance**
* **Abstraction**
* **Polymorphism**
